# 机械臂机械结构规范

> **文件用途**：定义机械臂运动学与动力学模型，供下位机重力补偿代码直接使用。  
> **阅读要求**：本文档必须自包含，不依赖任何外部对话历史。

---

## 1. 机械类型与布局

- **绳控机械臂**：所有驱动电机（大臂、小臂）均安装在底部底座内，通过绳索+关节四连杆机构传动。
- **云台**：底部水平旋转电机（yaw），位于桌面，驱动整个上方结构绕竖直轴旋转。
- **连接杆**：从云台竖直向上延伸，长度 0.45 m。
- **四连杆关节**：大臂关节和小臂关节处各有一根短连杆（Gear1、Gear2），它们**不是简单的传动摇臂，而是四连杆机构的一部分**，直接参与关节运动学约束。大臂/小臂不直接铰接在关节轴上，而是通过 Gear 杆驱动。
- **末端**：小臂末端之外延伸 0.073 m 安装摄像头，其俯仰由舵机独立控制。

> **注意**：下文采用"关节偏置杆"模型。大臂从 P1 出发、小臂从 P2 出发，P1/P2 位置随 Gear1/Gear2 的旋转而移动。

---

## 2. 坐标系定义

- **原点**：云台旋转中心（桌面高度）。
- **Z 轴**：竖直向上。
- **Y 轴**：水平向前（机械臂主运动平面为 Y-Z 平面）。
- **X 轴**：水平向右（右手系，垂直于运动平面）。

所有关节均在 Y-Z 平面内运动（暂不考虑云台水平旋转时，X = 0）。

## 4. 角度定义（核心，必须逐条理解）

### 4.1 大臂角 θ1

**定义**：大臂 L1 与**竖直向下方向**的夹角。

| θ1 | 大臂姿态 |
|---|---|
| `0` | 大臂竖直向下，指向地面 |
| `π/2` | 大臂水平向前 |
| `π` | 大臂竖直向上 |

**与电机关系**：大臂电机输出轴角度为 `θ_m1`，二者满足
```
θ1 = -θ_m1 / 4
```
即电机转 4 圈，大臂关节转 1 圈，方向相反。

> **电机方向**：大臂电机正转，大臂向内折叠（θ1 减小）。

### 4.2 小臂展开角 θ2

**定义**：小臂 L2 从**与大臂反向共线**位置开始，绕 J2 向**顺时针方向**（从用户侧 +X 方向看去）展开的展开角。

**几何含义**：
- `θ2 = 0`：小臂与大臂**反向共线**（两条线段在同一直线上，方向相反）。此时为**收起状态**（大臂竖直向下、小臂竖直向上，两者折叠在一起）。
- `θ2 = π/2`：小臂从反向位置顺时针展开 90°。若大臂水平向前（`θ1 = π/2`），此时小臂竖直向下。
- `θ2 = π`：小臂与大臂**同向共线**（完全伸直展开）。

**机械限制**：正常工作范围内 `θ2 ∈ [0, π]`。

**与电机关系**：小臂电机输出轴角度为 `θ_m2`，二者满足
```
θ2 = θ_m2 / 2
```
即电机转 2 圈，小臂关节转 1 圈，方向相同。

> **电机方向**：小臂电机正转，小臂顺时针展开（θ2 增大）。
> **零点**：收起时（大臂向下、小臂向上，两者折叠在一起）为零点，对应 `θ2 = 0`。

### 4.3 云台角 θ_gimbal

底座水平旋转角，与电机输出轴 `θ_m0` 为 1:1 直连。

> **电机方向**：云台电机从上向下看逆时针为正。
> **零点**：零点为正常点，与 Y 轴重合。

### 4.4 舵机角 φ_servo

摄像头俯仰角，相对于**小臂延长线**定义：
- `φ_servo = 0`：摄像头质心 E 沿小臂延长线向前（与小臂同向）。
- `φ_servo > 0`：摄像头向上抬头（绕 X 轴正方向，向 +Z 偏转）。
- `φ_servo < 0`：摄像头向下低头。

### 4.5 A009 舵机（小臂舵机）

A009 舵机安装在小臂末端，直接驱动摄像头/末端执行器。

| 舵机实际角度 | φ_servo | 末端姿态 |
|---|---|---|
| 0.6 rad（共线点）| 0 | 沿小臂延长线向前 |
| 0.6 + π/2 rad | +π/2 | 垂直于小臂向上 |
| 0 rad | −0.6 rad | 向内弯折极限 |

**接口定义**：代码中 `Motor_Position` **直接等于 `φ_servo`**。
- 驱动层自动叠加偏置 `+0.6 rad`，限幅到 `[0, π]`。
- 有效接口范围：`[-0.6, π - 0.6]` rad。

### 4.6 FT90M 舵机（摄像头舵机）

| 参数 | 数值 |
|---|---|
| 类型 | 280° 舵机 |
| 安装位置 | 与摄像头直接相连 |
| 旋转方向 | 自上而下看顺时针旋转 |
| 中心点 | 标称 140°，实测 **2.35 rad** |
| 软件偏置 | `FT90M_ANGLE_OFFSET_RAD = 2.35 - 2.443 ≈ -0.093 rad` |
| 驱动层限幅 | `[0, 4.887 rad]`（0°~280°）|

> FT90M 控制摄像头水平旋转（与主运动平面 Y-Z 内的运动学模型独立）。

### 4.7 Gear1 旋转角

Gear1 是绕 J1 旋转的摇臂，其**与竖直向下方向的夹角**为：
```
α_g1 = θ1 / 2 + π / 2
```

**物理意义**：
- `θ1 = 0`（大臂向下）：`α_g1 = π/2`，Gear1 **水平向前**。
- `θ1 = π`（大臂向上）：`α_g1 = π`，Gear1 **竖直向上**。

### 4.8 Gear2 旋转角

Gear2 是绕 J2 旋转的摇臂，其**与大臂方向的夹角**为：
```
α_g2_relative = π - θ2 / 2
```

即从大臂方向 `n̂_1` 出发，绕 X 轴逆时针旋转 `π - θ2/2` 得到 Gear2 方向。

**物理意义**：
- `θ2 = 0`（小臂反向共线）：Gear2 **垂直于大臂**（斜向后下）。
- `θ2 = π`（小臂同向共线）：Gear2 **与大臂同向**。

## 5. 方向向量推导

以下所有向量均在 Y-Z 平面内，X 分量为 0。

### 5.1 竖直向下参考向量

在 Z 向上坐标系中，竖直向下为：
```
d̂_down = (0, 0, -1)
```

从 `d̂_down` 绕 X 轴逆时针旋转角度 `α`，得到方向向量：
```
n̂(α) = (0, sin α, -cos α)
```

### 5.2 Gear1 方向

Gear1 与竖直向下夹角 `α_g1 = θ1/2 + π/2`：
```
n̂_g1 = n̂(θ1/2 + π/2)
     = (0, sin(θ1/2 + π/2), -cos(θ1/2 + π/2))
     = (0, cos(θ1/2), sin(θ1/2))
```

### 5.3 大臂方向

大臂与竖直向下夹角 `θ1`：
```
n̂_1 = n̂(θ1)
    = (0, sin θ1, -cos θ1)
```

### 5.4 Gear2 方向

Gear2 从大臂方向 `n̂_1` 出发，绕 X 轴逆时针旋转 `π - θ2/2`。

绕 X 轴旋转的旋转矩阵：
```
y' = y·cos β - z·sin β
z' = y·sin β + z·cos β
```
其中 `β = π - θ2/2`，`cos β = -cos(θ2/2)`，`sin β = sin(θ2/2)`。

代入 `n̂_1 = (0, sin θ1, -cos θ1)`：
```
y_g2 = sin θ1 · (-cos(θ2/2)) - (-cos θ1) · sin(θ2/2)
     = -sin θ1 · cos(θ2/2) + cos θ1 · sin(θ2/2)
     = -sin(θ1 + θ2/2)

z_g2 = sin θ1 · sin(θ2/2) + (-cos θ1) · (-cos(θ2/2))
     = sin θ1 · sin(θ2/2) + cos θ1 · cos(θ2/2)
     = cos(θ1 - θ2/2)
```

因此：
```
n̂_g2_raw = (0, -sin(θ1 + θ2/2), cos(θ1 - θ2/2))
```

> **实际安装方向修正**：根据机械实物，Gear2 杆的末端在正常工作范围内始终低于其起始点 J2，即 `n̂_g2` 的 Z 分量应为负。上述推导中 `cos(θ1 - θ2/2)` 在部分姿态下为正（指向上方），与实际安装相反。因此最终方向向量需整体取反：
>
> ```
> n̂_g2 = (0, sin(θ1 + θ2/2), -cos(θ1 - θ2/2))
> ```

### 5.5 小臂方向

小臂从"与大臂反向"位置开始，向**顺时针方向**展开 `θ2`。反向位置即 `-n̂_1`，顺时针展开相当于绕 X 轴**顺时针**旋转 `θ2`：

```
-n̂_1 = (0, -sin θ1, cos θ1)

绕 X 轴顺时针旋转 θ2（即逆时针旋转 -θ2）：
y' = y·cos(-θ2) - z·sin(-θ2) = y·cos θ2 + z·sin θ2
   = -sin θ1 · cos θ2 + cos θ1 · sin θ2
   = -sin(θ1 + θ2)

z' = y·sin(-θ2) + z·cos(-θ2) = -y·sin θ2 + z·cos θ2
   = sin θ1 · sin θ2 + cos θ1 · cos θ2
   = cos(θ1 + θ2)
```

因此：
```
n̂_2 = (0, -sin(θ1 + θ2), cos(θ1 + θ2))
```

**验证**：
- `θ2 = 0`：`n̂_2 = (0, -sin θ1, cos θ1) = -n̂_1`，反向重合（大臂向下则小臂向上）✓
- `θ2 = π`：`n̂_2 = (0, -sin(θ1 + π), cos(θ1 + π)) = (0, sin θ1, -cos θ1) = n̂_1`，同向重合 ✓
- `θ1 = π/2, θ2 = π/2`：`n̂_2 = (0, -sin(π), cos(π)) = (0, 0, -1)`，竖直向下 ✓
- `θ1 + θ2 = π`：`n̂_2 = (0, -sin(π), cos(π)) = (0, 0, -1)`，竖直向下 ✓（与用户事实"互补则向下"一致）

### 5.6 末端方向

末端从小臂方向再偏转 `φ_servo`（逆时针旋转，向上抬头）：
```
n̂_end = (0, -sin(θ1 + θ2 + φ_servo), cos(θ1 + θ2 + φ_servo))
```

## 6. 关节位置

```
J1 = (0, 0, L_connect)                              // 连接杆顶端

P1 = J1 + L_g1 · n̂_g1                                // 大臂根部（旋转轴点，随 Gear1 移动）
   = (0, L_g1·cos(θ1/2), L_connect + L_g1·sin(θ1/2))

J2 = P1 + L1 · n̂_1                                   // 大臂末端
   = (0,
      L_g1·cos(θ1/2) + L1·sin θ1,
      L_connect + L_g1·sin(θ1/2) - L1·cos θ1)

P2 = J2 + L_g2 · n̂_g2                                // 小臂根部（旋转轴点，随 Gear2 移动）
   = J2 + (0, L_g2·sin(θ1 + θ2/2), -L_g2·cos(θ1 - θ2/2))

J3 = P2 + L2 · n̂_2                                   // 小臂末端
   = (0,
      y_P2 - L2·sin(θ1 + θ2),
      z_P2 + L2·cos(θ1 + θ2))

E  = J3 + L_end · n̂_end
   = (0,
      y_J3 - L_end·sin(θ1 + θ2 + φ_servo),
      z_J3 + L_end·cos(θ1 + θ2 + φ_servo))
```

## 7. 各部件质心位置

假设所有杆均匀分布，质心在中点。末端质量集中于 E 点。

| 部件 | 质心坐标 | Z 向高度 |
|---|---|---|
| Gear1 | `C_g1 = J1 + (L_g1/2)·n̂_g1` | `z_g1 = L_connect + (L_g1/2)·sin(θ1/2)` |
| 大臂 | `C_1 = P1 + (L1/2)·n̂_1` | `z_1 = L_connect + L_g1·sin(θ1/2) - (L1/2)·cos θ1` |
| Gear2 | `C_g2 = J2 + (L_g2/2)·n̂_g2` | `z_g2 = L_connect + L_g1·sin(θ1/2) - L1·cos θ1 - (L_g2/2)·cos(θ1 - θ2/2)` |
| 小臂 | `C_2 = P2 + (L2/2)·n̂_2` | `z_2 = L_connect + L_g1·sin(θ1/2) - L1·cos θ1 - L_g2·cos(θ1 - θ2/2) + (L2/2)·cos(θ1 + θ2)` |
| 末端 | `C_end = E` | `z_end = L_connect + L_g1·sin(θ1/2) - L1·cos θ1 - L_g2·cos(θ1 - θ2/2) + L2·cos(θ1 + θ2) + L_end·cos(θ1 + θ2 + φ_servo)` |

## 8. 重力补偿推导

### 8.1 方法

势能法：
1. 计算总重力势能 `V = Σ m_i · g · z_i`
2. 求关节广义力 `Q = -∂V/∂θ`
3. 按电机传动比折算到**电机输出轴力矩**

### 8.2 对 θ1 的偏导数

```
∂V/∂θ1 =
    m_g1·g·(L_g1/4)·cos(θ1/2)
  + m1·g·[(L_g1/2)·cos(θ1/2) + (L1/2)·sin θ1]
  + m_g2·g·[(L_g1/2)·cos(θ1/2) + L1·sin θ1 + (L_g2/2)·sin(θ1 - θ2/2)]
  + m2·g·[(L_g1/2)·cos(θ1/2) + L1·sin θ1 + L_g2·sin(θ1 - θ2/2) - (L2/2)·sin(θ1 + θ2)]
  + m_end·g·[(L_g1/2)·cos(θ1/2) + L1·sin θ1 + L_g2·sin(θ1 - θ2/2) - L2·sin(θ1 + θ2) - L_end·sin(θ1 + θ2 + φ_servo)]
```

**大臂关节广义力**（重力使 θ1 变化的趋势）：
```
Q1 = -∂V/∂θ1
```

**大臂电机补偿力矩**（传动比 4:1，折算到电机输出轴）：
```
τ_m1 = Q1 / 4 = -(∂V/∂θ1) / 4
```

### 8.3 对 θ2 的偏导数

```
∂V/∂θ2 =
  - m_g2·g·(L_g2/4)·sin(θ1 - θ2/2)
  - m2·g·[(L_g2/2)·sin(θ1 - θ2/2) + (L2/2)·sin(θ1 + θ2)]
  - m_end·g·[(L_g2/2)·sin(θ1 - θ2/2) + L2·sin(θ1 + θ2) + L_end·sin(θ1 + θ2 + φ_servo)]
```

**小臂关节广义力**：
```
Q2 = -∂V/∂θ2
```

**小臂电机补偿力矩**（传动比 2:1，折算到电机输出轴）：
```
τ_m2 = Q2 / 2 = -(∂V/∂θ2) / 2
```

### 8.4 符号约定

- `τ > 0`：电机输出轴产生**正方向力矩**（使电机读数 `θ_m` **增大**）。
- 由于 `θ1 = -θ_m1/4`，当 `τ_m1 > 0` 时，电机读数增大，θ1 **减小**（大臂向下转）。
- 由于 `θ2 = θ_m2/2`，当 `τ_m2 > 0` 时，电机读数增大，θ2 **增大**（小臂向下展开）。
- 若实际测试发现重力补偿方向相反，说明电机正方向与模型假设相反，整体取反即可。

## 9. 典型姿态验证（用于公式自查）

### 姿态 A：收起状态（大臂向下、小臂向上）

`θ1 = 0, θ2 = 0, φ_servo = 0`

| 部件 | 方向向量 | Z 高度 |
|---|---|---|
| Gear1 | `(0, 1, 0)` 水平向前 | `L_connect` |
| P1（大臂根部）| — | `L_connect` |
| 大臂 | `(0, 0, -1)` 竖直向下 | `L_connect - L1/2` |
| J2（大臂末端）| — | `L_connect - L1` |
| Gear2 | `(0, 0, -1)` 竖直向下 | `L_connect - L1` |
| P2（小臂根部）| — | `L_connect - L1 - L_g2` |
| 小臂 | `(0, 0, 1)` 竖直向上 | `L_connect - L1 - L_g2 + L2/2` |
| J3（小臂末端）| — | `L_connect - L1 - L_g2 + L2` |
| 末端 | `(0, 0, 1)` 竖直向上 | `L_connect - L1 - L_g2 + L2 + L_end` |

**重力补偿**：
- `∂V/∂θ1 = m_g1·g·L_g1/4 + m1·g·L_g1/2 + m_g2·g·(L_g1/2 + L_g2/2) + m2·g·(L_g1/2 + L_g2) + m_end·g·(L_g1/2 + L_g2)`
- `∂V/∂θ2 = 0`（所有质量在竖直线上，θ2 变化不改变质心高度）
- `τ_m1 = -(∂V/∂θ1)/4`
- `τ_m2 = 0`

### 姿态 B：大臂水平，小臂竖直向下

`θ1 = π/2, θ2 = π/2, φ_servo = 0`

| 部件 | 方向向量 | Z 高度 |
|---|---|---|
| Gear1 | `(0, cos(π/4), sin(π/4))` 斜向前上 | `L_connect + (L_g1/2)·sin(π/4)` |
| P1 | — | `L_connect + L_g1·sin(π/4)` |
| 大臂 | `(0, 1, 0)` 水平向前 | `L_connect + L_g1·sin(π/4)` |
| J2 | — | `L_connect + L_g1·sin(π/4)` |
| Gear2 | `(0, sin(3π/4), -cos(π/4))` 斜向前下 | `L_connect + L_g1·sin(π/4) - (L_g2/2)·cos(π/4)` |
| P2 | — | `L_connect + L_g1·sin(π/4) - L_g2·cos(π/4)` |
| 小臂 | `(0, 0, -1)` 竖直向下 | `L_connect + L_g1·sin(π/4) - L_g2·cos(π/4) - L2/2` |
| J3 | — | `L_connect + L_g1·sin(π/4) - L_g2·cos(π/4) - L2` |
| 末端 | `(0, 0, -1)` 竖直向下 | `L_connect + L_g1·sin(π/4) - L_g2·cos(π/4) - L2 - L_end` |

> 此姿态下大臂水平向前、小臂竖直向下，θ1+θ2=π，与用户事实一致。

### 姿态 C：完全伸直水平

`θ1 = π/2, θ2 = π, φ_servo = 0`
（此时小臂与大臂同向，均水平向前）

| 部件 | 方向向量 | Z 高度 |
|---|---|---|
| Gear1 | `(0, cos(π/4), sin(π/4))` 斜向前上 | `L_connect + (L_g1/2)·sin(π/4)` |
| P1 | — | `L_connect + L_g1·sin(π/4)` |
| 大臂 | `(0, 1, 0)` 水平向前 | `L_connect + L_g1·sin(π/4)` |
| J2 | — | `L_connect + L_g1·sin(π/4)` |
| Gear2 | `(0, sin(π), -cos(0))` 即 `(0, 0, -1)` 竖直向下 | `L_connect + L_g1·sin(π/4) - L_g2/2` |
| P2 | — | `L_connect + L_g1·sin(π/4) - L_g2` |

## 10. 运动学模型说明

### 10.1 关节偏置杆结构

本模型采用**关节偏置杆**假设：
- **Gear1** 是连接 J1 与大臂根部 P1 的短杆（长度 0.054 m）
- **大臂 L1** 从 P1 出发到 J2（长度 0.43 m）
- **Gear2** 是连接 J2 与小臂根部 P2 的短杆（长度 0.026 m）
- **小臂 L2** 从 P2 出发到 J3（长度 0.2883 m）

大臂/小臂的实际旋转轴点 P1/P2 **不是固定的 J1/J2**，而是随 Gear1/Gear2 的旋转而移动。

### 10.2 逆运动学

**注意**：定位点已改为**小臂末端 J3**（不再是摄像头光心 E）。phi_servo 仅用于舵机控制，不再影响臂部逆解算。

J3 与关节角 θ1/θ2 的关系为：

```
J3 = J1 + L_g1·n̂_g1 + L1·n̂_1 + L_g2·n̂_g2 + L2·n̂_2
```

给定目标坐标 (X, Y, Z)，求解 θ1 和 θ2 需要解上述非线性方程组。由于 L_g1 和 L_g2 相对于 L1、L2 较小，可考虑：

1. **数值迭代法**（牛顿-拉夫逊），在嵌入式系统中开销较大
2. **近似解析法**：先忽略 Gear 杆，用传统二连杆模型求解初值，再迭代修正
3. **查表/插值法**：离线计算密集查表，运行时插值

标准二连杆模型（新 θ2 定义，定位点 J3）：
- 第一杆（大臂）方向角 = θ1（从竖直向下顺时针）
- 第二杆（小臂 J2→J3）绝对方向角 = θ1 + π + β，其中 `β = θ2`
- 末端相对 J1 的位置：`R = L1·sin θ1 - L2·sin(θ1 + β)`，`Z - L_connect = -L1·cos θ1 + L2·cos(θ1 + β)`
- 由余弦定理：`cos(β) = (L1² + L2² - R² - (Z-L_connect)²) / (2·L1·L2)`
- 再由几何关系求 θ1 = atan2(R, -(Z-L_connect)) + acos((L1² + R²+(Z-L_connect)² - L2²) / (2·L1·√(R²+(Z-L_connect)²)))
