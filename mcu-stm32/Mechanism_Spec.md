# 机械臂机械结构规范

> **文件用途**：定义机械臂运动学与动力学模型，供下位机重力补偿代码直接使用。  
> **阅读要求**：本文档必须自包含，不依赖任何外部对话历史。

---

## 1. 机械类型与布局

- **绳控机械臂**：所有驱动电机（大臂、小臂）均安装在底部底座内，通过绳索+关节摇臂传动。
- **云台**：底部水平旋转电机（yaw），位于桌面，驱动整个上方结构绕竖直轴旋转。
- **连接杆**：从云台竖直向上延伸，长度 0.45 m，仅作结构支撑，不传递关节力矩。
- **关节摇臂**：大臂关节和小臂关节处各有一根短连杆（Gear1、Gear2），它们本身就是关节机构的一部分，有质量、有长度、绕关节轴旋转。
- **末端**：小臂末端之外延伸 0.073 m 安装摄像头，其俯仰由舵机独立控制。

---

## 2. 坐标系定义

- **原点**：云台旋转中心（桌面高度）。
- **Z 轴**：竖直向上。
- **Y 轴**：水平向前（机械臂主运动平面为 Y-Z 平面）。
- **X 轴**：水平向右（右手系，垂直于运动平面）。

所有关节均在 Y-Z 平面内运动（暂不考虑云台水平旋转时，X = 0）。

## 4. 角度定义（核心，必须逐条理解）

### 4.1 大臂角 θ1

**定义**：大臂 L1 与**竖直向下方向**的夹角。

| θ1 | 大臂姿态 |
|---|---|
| `0` | 大臂竖直向下，指向地面 |
| `π/2` | 大臂水平向前 |
| `π` | 大臂竖直向上 |

**与电机关系**：大臂电机输出轴角度为 `θ_m1`，二者满足
```
θ1 = -θ_m1 / 4
```
即电机转 4 圈，大臂关节转 1 圈，方向相反。

### 4.2 小臂展开角 θ2

**定义**：小臂 L2 从**与大臂反向共线**位置开始，绕 J2 旋转的展开角。

**几何含义**：
- `θ2 = 0`：小臂与大臂**反向共线**（两条线段在同一直线上，方向相反）。此时大臂末端与小臂末端距离最短，为 `|L1 - L2|`。
- `θ2 = π`：小臂与大臂**同向共线**（两条线段在同一直线上，方向相同）。此时大臂末端与小臂末端距离最长，为 `L1 + L2`。
- `θ2 > π`：小臂继续旋转，翻到大臂的"上方"。

**注意**：θ2 **不是**两条线之间的"几何夹角"。它是从"反向位置"开始计量的展开角。

**与电机关系**：小臂电机输出轴角度为 `θ_m2`，二者满足
```
θ2 = θ_m2 / 2
```
即电机转 2 圈，小臂关节转 1 圈，方向相同。

### 4.3 云台角 θ_gimbal

底座水平旋转角，与电机输出轴 `θ_m0` 为 1:1 直连。

### 4.4 舵机角 φ_servo

摄像头俯仰角，相对于**小臂延长线**定义：
- `φ_servo = 0`：摄像头质心 E 沿小臂延长线向前（与小臂同向）。
- `φ_servo > 0`：摄像头向上抬头（绕 X 轴正方向，向 +Z 偏转）。
- `φ_servo < 0`：摄像头向下低头。

### 4.5 Gear1 旋转角

Gear1 是绕 J1 旋转的摇臂，其**与竖直向下方向的夹角**为：
```
α_g1 = θ1 / 2 + π / 2
```

**物理意义**：
- `θ1 = 0`（大臂向下）：`α_g1 = π/2`，Gear1 **水平向前**。
- `θ1 = π`（大臂向上）：`α_g1 = π`，Gear1 **竖直向上**。

### 4.6 Gear2 旋转角

Gear2 是绕 J2 旋转的摇臂，其**与大臂方向的夹角**为：
```
α_g2_relative = θ2 / 2 + π / 2
```

即从大臂方向 `n̂_1` 出发，绕 X 轴逆时针旋转 `θ2/2 + π/2` 得到 Gear2 方向。

**物理意义**：
- `θ2 = 0`（小臂反向）：Gear2 **垂直于大臂**。
- `θ2 = π`（小臂同向）：Gear2 **与大臂反向**。

## 5. 方向向量推导

以下所有向量均在 Y-Z 平面内，X 分量为 0。

### 5.1 竖直向下参考向量

在 Z 向上坐标系中，竖直向下为：
```
d̂_down = (0, 0, -1)
```

从 `d̂_down` 绕 X 轴逆时针旋转角度 `α`，得到方向向量：
```
n̂(α) = (0, sin α, -cos α)
```

### 5.2 Gear1 方向

Gear1 与竖直向下夹角 `α_g1 = θ1/2 + π/2`：
```
n̂_g1 = n̂(θ1/2 + π/2)
     = (0, sin(θ1/2 + π/2), -cos(θ1/2 + π/2))
     = (0, cos(θ1/2), sin(θ1/2))
```

### 5.3 大臂方向

大臂与竖直向下夹角 `θ1`：
```
n̂_1 = n̂(θ1)
    = (0, sin θ1, -cos θ1)
```

### 5.4 Gear2 方向

Gear2 从大臂方向 `n̂_1` 出发，绕 X 轴逆时针旋转 `θ2/2 + π/2`。

绕 X 轴旋转的旋转矩阵：
```
y' = y·cos β - z·sin β
z' = y·sin β + z·cos β
```
其中 `β = θ2/2 + π/2`，`cos β = -sin(θ2/2)`，`sin β = cos(θ2/2)`。

代入 `n̂_1 = (0, sin θ1, -cos θ1)`：
```
y_g2 = sin θ1 · (-sin(θ2/2)) - (-cos θ1) · cos(θ2/2)
     = cos θ1 · cos(θ2/2) - sin θ1 · sin(θ2/2)
     = cos(θ1 + θ2/2)

z_g2 = sin θ1 · cos(θ2/2) + (-cos θ1) · (-sin(θ2/2))
     = sin θ1 · cos(θ2/2) + cos θ1 · sin(θ2/2)
     = sin(θ1 + θ2/2)
```

因此：
```
n̂_g2 = (0, cos(θ1 + θ2/2), sin(θ1 + θ2/2))
```

### 5.5 小臂方向

小臂从"与大臂反向"位置展开 `θ2`。反向位置即 `-n̂_1`，从 `-n̂_1` 绕 X 轴逆时针旋转 `θ2` 得到小臂方向：

从 `n̂_1` 出发旋转 `π - θ2`（因为反向到同向需转 π，再展开 θ2）：
```
n̂_2 = (0, sin(θ2 - θ1), cos(θ2 - θ1))
```

**验证**：
- `θ2 = 0`：`n̂_2 = (0, -sin θ1, cos θ1) = -n̂_1`，反向重合 ✓
- `θ2 = π`：`n̂_2 = (0, sin θ1, -cos θ1) = n̂_1`，同向重合 ✓

### 5.6 末端方向

末端从小臂方向再偏转 `φ_servo`：
```
n̂_end = (0, sin(θ2 - θ1 + φ_servo), cos(θ2 - θ1 + φ_servo))
```

## 6. 关节位置

```
J1 = (0, 0, L_connect)

J2 = J1 + L1 · n̂_1
   = (0, L1·sin θ1, L_connect - L1·cos θ1)

J3 = J2 + L2 · n̂_2
   = (0,
      L1·sin θ1 + L2·sin(θ2 - θ1),
      L_connect - L1·cos θ1 + L2·cos(θ2 - θ1))

E  = J3 + L_end · n̂_end
   = (0,
      L1·sin θ1 + L2·sin(θ2 - θ1) + L_end·sin(θ2 - θ1 + φ_servo),
      L_connect - L1·cos θ1 + L2·cos(θ2 - θ1) + L_end·cos(θ2 - θ1 + φ_servo))
```

## 7. 各部件质心位置

假设所有杆均匀分布，质心在中点。末端质量集中于 E 点。

| 部件 | 质心坐标 | Z 向高度 |
|---|---|---|
| Gear1 | `C_g1 = J1 + (L_g1/2)·n̂_g1` | `z_g1 = L_connect + (L_g1/2)·sin(θ1/2)` |
| 大臂 | `C_1 = J1 + (L1/2)·n̂_1` | `z_1 = L_connect - (L1/2)·cos θ1` |
| Gear2 | `C_g2 = J2 + (L_g2/2)·n̂_g2` | `z_g2 = L_connect - L1·cos θ1 + (L_g2/2)·sin(θ1 + θ2/2)` |
| 小臂 | `C_2 = J2 + (L2/2)·n̂_2` | `z_2 = L_connect - L1·cos θ1 + (L2/2)·cos(θ2 - θ1)` |
| 末端 | `C_end = E` | `z_end = L_connect - L1·cos θ1 + L2·cos(θ2 - θ1) + L_end·cos(θ2 - θ1 + φ_servo)` |

## 8. 重力补偿推导

### 8.1 方法

势能法：
1. 计算总重力势能 `V = Σ m_i · g · z_i`
2. 求关节广义力 `Q = -∂V/∂θ`
3. 按电机传动比折算到**电机输出轴力矩**

### 8.2 对 θ1 的偏导数

```
∂V/∂θ1 =
    m_g1·g·(L_g1/4)·cos(θ1/2)
  + m1·g·(L1/2)·sin θ1
  + m_g2·g·[L1·sin θ1 + (L_g2/2)·cos(θ1 + θ2/2)]
  + m2·g·[L1·sin θ1 + (L2/2)·sin(θ2 - θ1)]
  + m_end·g·[L1·sin θ1 + L2·sin(θ2 - θ1) + L_end·sin(θ2 - θ1 + φ_servo)]
```

**大臂关节广义力**（重力使 θ1 变化的趋势）：
```
Q1 = -∂V/∂θ1
```

**大臂电机补偿力矩**（传动比 4:1，折算到电机输出轴）：
```
τ_m1 = Q1 / 4 = -(∂V/∂θ1) / 4
```

### 8.3 对 θ2 的偏导数

```
∂V/∂θ2 =
    m_g2·g·(L_g2/4)·cos(θ1 + θ2/2)
  - m2·g·(L2/2)·sin(θ2 - θ1)
  - m_end·g·[L2·sin(θ2 - θ1) + L_end·sin(θ2 - θ1 + φ_servo)]
```

**小臂关节广义力**：
```
Q2 = -∂V/∂θ2
```

**小臂电机补偿力矩**（传动比 2:1，折算到电机输出轴）：
```
τ_m2 = Q2 / 2 = -(∂V/∂θ2) / 2
```

### 8.4 符号约定

- `τ > 0`：电机输出轴产生**正方向力矩**（使电机读数 `θ_m` **增大**）。
- 由于 `θ1 = -θ_m1/4`，当 `τ_m1 > 0` 时，电机读数增大，θ1 **减小**（大臂向下转）。
- 若实际测试发现重力补偿方向相反，说明电机正方向与模型假设相反，整体取反即可。

- `τ_m2 = -m_g2·g·L_g2/8`
