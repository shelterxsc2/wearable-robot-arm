## 进度表述规则

- 可以写“构建通过”：完整 C++ 已成功编译。
- 可以写“纯逻辑测试”：FIRST_PERSON 映射和控制回放有测试。
- 手部单次约 8 ms 只能写“阶段性单 ROI 推理结果”。
- 完整视觉约 13～15 FPS 必须写“实机阶段性观察/待长测”，不能承诺恒定值。
- 手势可写“情景控制代码已接入并有纯决策测试”，同时必须注明准确率、误触发、退出回中和机械安全尚未实机验收。
- FIRST_PERSON、云端真实下行、蓝牙和双手长测必须列为未完成实机验收。
- 仿真不能宣称验证了碰撞、动力学或 UART 实时性。
