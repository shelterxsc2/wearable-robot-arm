# 上下位机 UART 通信协议

## 物理层

| 参数 | 值 |
|------|-----|
| 接口 | UART (TTL) |
| 建议设备 | `/dev/ttyS1` 或 `/dev/ttyUSB0` |
| 波特率 | **921600** (推荐) 或 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验 | 无 |
| 流控 | 无 |

## 帧格式

```
+--------+--------+-----+-----+----------+------+
| 0xAA   | 0x55   | LEN | CMD | payload  | CRC8 |
+--------+--------+-----+-----+----------+------+
| 1 byte | 1 byte | 1B  | 1B  | N bytes  | 1B   |
```

- `LEN`: payload 长度，0~250
- `CRC8`: `LEN + CMD + payload` 的累加和取低 8 位

## 命令定义

### 0x01 — HEARTBEAT
- **方向**: 双向
- **payload**: 无 (LEN=0)
- **说明**: 握手/保活

### 0x10 — TARGET_POSE
- **方向**: 上位机 -> 下位机
- **payload**: 28 字节 (`Pose6D` 结构)
- **说明**: 上位机计算出的目标相机位姿

```c
typedef struct {
    float x, y, z;        // 位置, mm
    float qx, qy, qz, qw; // 四元数, 归一化
} Pose6D;
```

### 0x20 — CURRENT_POSE
- **方向**: 下位机 -> 上位机
- **payload**: 28 字节 (`Pose6D` 结构)
- **说明**: 下位机回传的当前末端（相机）位姿

### 0x30 — ARM_TARGET
- **方向**: 上位机 -> 下位机
- **payload**: 10 字节 (5 × int16 小端)
- **说明**: 简化指令，直接发空间坐标 + 舵机角度

```c
typedef struct {
    int16_t x, y, z;   // cm
    int16_t k1, k2;    // 度
} ArmTarget;
```

## 坐标系定义

### 机械臂基座系
- **原点**: J1 关节中心
- **+Z**: 竖直向上
- **+X**: 人脸右侧（从人脸自身视角）
- **+Y**: 人脸下方 → 实际机械臂前方

### 人脸坐标系 (PnP 输出)
见 `host-rk3588/rga_npu.cpp` 中的 `FACE_3D_POINTS` 定义。

## 通信流程

```
上位机 (RK3588)                    下位机 (STM32)
     |                                  |
     |--- TARGET_POSE (0x10) --------->|  目标位姿下发
     |                                  |
     |<-- CURRENT_POSE (0x20) ---------|  当前位姿回传
     |                                  |
     |--- HEARTBEAT (0x01) ----------->|  定期保活（建议 1Hz）
```

## 注意事项

1. **字节序**: 所有多字节数据采用 **小端 (Little-Endian)**
2. **四元数**: 必须归一化，`qx² + qy² + qz² + qw² = 1`
3. **丢帧处理**: 下位机若 500ms 未收到 TARGET_POSE，应保持当前轨迹或减速停车
4. **频率**: TARGET_POSE 建议以 30Hz（与视觉帧率同步）或至少 10Hz 下发
