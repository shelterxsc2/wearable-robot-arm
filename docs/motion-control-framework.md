## 一、背景与核心矛盾

### 1.1 系统时域对比

| 对象 | 运动/响应周期 | 特性 |
|:---|:---|:---|
| **人脸运动** | 100ms ~ 250ms | 快速、敏捷、可突变 |
| **机械臂（三轴）** | 400ms ~ 2000ms | 慢速、惯性大、短距离更慢 |
| **上位机控制周期** | 50ms（GLib 定时器） | 固定间隔，可调 |
| **下位机控制周期** | 1ms | S 曲线规划、电机驱动 |
| **NRF24 采样周期** | ~10ms（100Hz 有效速率） | 独立于视觉帧 |
| **舵机 J4** | ~50ms | 快速、小范围、与机械臂耦合 |

> ⚠️ 舵机不是独立云台，J4 参与逆运动学，改变 Servo1 会牵动 J1/J2/J3。

### 1.2 核心矛盾

**机械臂响应比人脸慢，两者处于同一量级但机械臂更慢。**

这意味着：
- ❌ **反馈控制不可行**：等看到人脸动了再发指令，机械臂到位时人脸早已到了新位置
- ✅ **预测控制是唯一出路**：必须在人脸运动早期预判其最终稳态位置，让机械臂和人脸"同时到达"

## 二、人脸运动模型

### 2.1 简化模型（单周期）

```
速度
│         ┌──────────┐
│        ╱            ╲
│       ╱   匀速阶段   ╲
│      ╱   (wz = wz_0)  ╲
│     ╱                    ╲
│    ╱  变加速              ╲  变减速
│   ╱   (方向 k)             ╲  (方向 k', k' = -k)
│  ╱                            ╲
└────────────────────────────────────→ t
静止       加速              匀速              减速      静止
```

### 2.2 复杂模型（多平台 + 连续运动）

实际人脸运动不是简单的单峰梯形，匀速阶段可能发生以下 4 种情况：

| 情况 | 物理意义 | 速度曲线 |
|:---|:---|:---|
| **1. 跃升加速** | 转头过程中发现目标，加快速度 | 平台A → 变加速 → 平台B（\|B\|>\|A\|） |
| **2. 跃升减速** | 接近目标，主动降速对准 | 平台A → 变减速 → 平台B（\|B\|<\|A\|） |
| **3. 速度抖动** | 颈部肌肉微调，速度在原平台邻域波动 | 平台A ± Δ 范围内短周期加减速 |
| **4. 保持匀速** | 稳定跟踪，速度不变 | 平台A 延续 |
| **5. 连续运动（摇头）** | 扫视/摇头：A → 0 → -B | 变加速→匀速→变减速→**静止(0)**→反向变加速 |

### 2.3 关键定义

- **静止**：\|wz\| < 3 deg/s（纯速度判定，不看加速度）
- **速度平台**：\|wz\| 维持在某个水平带内，加速度在零附近波动
- **过零瞬态**：减速到 \|wz\|<3 后未停留直接反向加速，速度曲线呈 **V 型** 而非 U 型

### 2.4 时域约束

人脸运动周期（100ms~250ms）远大于控制采样周期（50ms），因此：
- 每个运动阶段至少持续 **2~10 个采样点**
- 过零瞬态（1~2 个采样点 = 50~100ms）可安全判定为"假静止"
- 真静止需持续 **≥2 个采样点（100ms）** 才确认

## 三、机械臂运动特性

### 3.1 S 曲线 7 相速度规划

下位机采用完整 7 相 S 曲线：

```
加加速 → 匀加速 → 减加速 → 匀速 → 加减速 → 匀减速 → 减减速
(phase1)  (phase2)  (phase3)  (phase4)  (phase5)  (phase6)  (phase7)
```

**关键参数**：

| 关节 | j (rad/s³) | a_max (rad/s²) | v_max (rad/s) |
|:---|:---:|:---:|:---:|
| 云台 (J1/Pan) | 15.5 | 2.5 | 0.75 |
| 大臂 (J2) | 15.5 | 1.5 | 0.45 |
| 小臂 (J3) | 15.5 | 1.5 | 0.45 |

### 3.2 短距离衰减（致命特性）

末端位移越小，速度限制越严格：

| 末端位移 S | 速度限制比例 | j_limit | 估算到位时间 |
|:---|:---:|:---:|:---:|
| S < 3cm | 15% | 6.0 | **~1.5s+** |
| 3cm ≤ S < 6cm | 20% | 8.0 | ~1.2s |
| 6cm ≤ S < 15cm | 30% | 10.0 | ~800ms |
| S ≥ 15cm | 100% | 15.5 | ~400ms |

**悖论：小位移修正比大位移运动更慢。**

### 3.3 方向反转惩罚

```c
if (old_direction * new_direction < 0) {
    Speed_Plan_Handle->v *= 0.3f;  // 反向时继承速度骤降到 30%
}
```

**后果**：摇头场景下连续发送反向指令会让机械臂极度迟缓。

### 3.4 指令重置效应

下位机每次收到 UART 指令都会执行：
```c
Speed_Plan_Handle->Speed_Plan_State = init;
```

**后果**：
- 高频发指令（<200ms）→ S 曲线不断重置 → 机械臂永远跑不完加速段
- 低频发指令（≥400ms）→ 有机会完整跑完 7 相 S 曲线 → 速度能达到 v_max

### 3.5 死区与滤波

| 参数 | 值 | 说明 |
|:---|:---|:---|
| 位置死区 | 1.5cm | X/Y/Z 任一方向变化 <1.5cm 时忽略新指令 |
| 舵机死区 | ≈2.9° | Servo1 变化 <2.9° 时忽略 |
| 一阶低通 | α = 0.65 | 目标位置平滑滤波 |

**可利用特性**：上位机连续发送的小幅变化（<1.5cm）会被下位机死区过滤，即使发了指令也不重置 S 曲线。

## 四、信息价值分析

### 4.1 信息价值密度

不同运动状态下，采样信息对预测终点的价值差异巨大：

| 人脸状态 | 信息价值 | 原因 |
|:---|:---:|:---|
| **静止→加速（启动）** | ⭐⭐⭐⭐⭐ | 方向确立，初始加速度大小预示运动规模 |
| **加速中** | ⭐⭐⭐⭐☆ | 加速持续时间 ∝ 最终速度平台高度 |
| **加速→匀速** | ⭐⭐⭐⭐⭐ | **关键转折点**：速度平台已确定，可据此预测终点 |
| **匀速 / 抖动** | ⭐☆☆☆☆ | 速度已知但无法预测何时结束，信息价值极低 |
| **匀速→减速** | ⭐⭐⭐⭐⭐ | **关键转折点**：运动开始结束，可估算剩余位移 |
| **减速→停止** | ⭐⭐⭐★☆ | 终点即将确定，但机械臂响应已滞后 |
| **停止** | ⭐⭐⭐☆☆ | 位置已知，但此时发指令机械臂已滞后 |

### 4.2 关键洞察

1. **初始加速阶段越长 → 预计终点越远**
   - 加速时间 t_acc ≈ 50~100ms
   - 末速度 wz_0 = ∫a·dt
   - 若总周期 ≤250ms，预测总转角 ≈ wz_0 × (0.15~0.20s) × 系数

2. **匀速/抖动阶段的信息为何无价值**
   - 已知 wz ≈ wz_0，但**不知道何时开始减速**
   - 无法预测 t_const 持续时间
   - 此时即使知道当前速度，也无法预测最终停止位置

3. **减速阶段的高价值时刻**
   - **匀速→减速**：若之前未发过指令，这是最后机会紧急补发
   - **减速→停止**：可精确锁定最终位置，用于离线修正预测模型

## 五、概率预测模型

将确定性单点预测升级为概率分布预测，用几何形态表达预测置信度。

### 5.1 基础版：速度不确定性球体

```
当前位置 P₀，速度 v，预测窗口 Δt（自适应，典型 200ms）

球心:  C = P₀ + v × Δt
半径:  R = |v| × Δt × σ_v        （σ_v: 速度不确定系数，如 0.3）

物理意义：
  下一时刻人脸位置 P 以最高概率落在球内：|P - C| ≤ R
  速度越大 → 球越大 → 预测越不可靠
```

### 5.2 Plus版：加速度方向拉伸椭球

```
加速度 a，将球体沿 a 方向拉伸为椭球

球心偏移:  C' = C + 0.5 × a × Δt²
长轴（a 方向）:  R_∥ = R + 0.5 × |a| × Δt² × σ_a
短轴（垂直方向）: R_⊥ = R
```

### 5.3 Ultra Plus版：状态调制拉伸系数

| 状态 | 拉伸系数 k | 几何形态 | 物理意义 |
|:---|:---:|:---|:---|
| 静止→加速 | 1.2 | 明显椭球 | 运动刚启动，趋势明确 |
| 加速中 | 1.5 | 强拉伸椭球 | 加速度主导，终点沿加速度方向大幅偏移 |
| 加速→匀速 | 0.8 | 弱拉伸椭球 | 加速度趋零，趋向球体 |
| 匀速 | 0.3 | 接近球体 | 速度稳定，但不知何时减速 |
| **速度抖动** | **0.0** | **标准球体** | 加速度正负交替，无方向偏好，**不拉伸** |
| 匀速→减速 | -0.8 | 弱拉伸（反向） | 减速趋势初现 |
| 减速→停止 | -1.2 | 明显椭球（反向） | 加速度明确反向，终点在后方收敛 |
| 停止 | 0.0 | **点** | 位置确定，R = 0 |

### 5.4 预测窗口 Δt 的自适应

```
Δt 不是固定的，而是根据预测位移自适应：

if (S_pred < 3cm)       Δt = 1.5s;   // 小位移慢，给机械臂更多时间
else if (S_pred < 15cm)  Δt = 0.8s;
else                      Δt = 0.4s;   // 大位移快，机械臂能迅速到位
```

## 六、控制策略框架

### 6.1 核心思想

```
不是"每50ms发一次指令"，
而是"只在信息价值高的时刻更新预测模型，
    只在预测置信度高且机械臂来得及响应的时刻发指令"。
```

### 6.2 采样与发指令分离

| 环节 | 频率 | 职责 | 所在线程 |
|:---|:---|:---|:---|
| **采样** | ~100Hz（每次 NRF24 valid 帧） | 更新 wz、ast、运动状态、概率预测模型 | NRF24 RX 线程 |
| **决策** | 50ms（或事件触发） | 评估预测中心变化、置信度、发指令时机 | 主线程/GLib 定时器 |
| **发指令** | 变速（30ms~400ms+） | UART 发送目标位置 | 主线程 |

### 6.3 发指令触发条件

```cpp
// 条件1：预测中心变化超过阈值
bool center_moved = fabsf(pred.center - last_cmd_center) > CMD_THRESHOLD;  // 建议 5°

// 条件2：置信度足够（球/椭球不能太大）
bool confident = pred.radius < MAX_RADIUS_THRESHOLD;

// 条件3：状态允许（抖动期不发）
bool state_ok = (state != STATE_JITTER);

// 条件4：最小间隔约束（给机械臂跑完加速段的时间）
bool interval_ok = (now - last_cmd_time >= MIN_CMD_INTERVAL_MS);  // 建议 200ms

// 条件5：方向反转紧急 bypass
bool reverse_urgent = direction_flipped && (now - last_cmd_time >= 100ms);
```

### 6.4 两个发指令窗口

| 窗口 | 触发条件 | 预测依据 | 机械臂能否赶上 |
|:---|:---|:---|:---:|
| **#1 主窗口** | 检测到 **加速→匀速** | wz_0 + 运动周期经验值 | ✅ 能，此时人脸才走了约 1/3 周期 |
| **#2 补救窗口** | **匀速→减速** 且 #1 未发 | 当前 wz + 减速距离估算 | ⚠️ 可能滞后，但比不发好 |

### 6.5 小误差不发原则

```cpp
if (|Δyaw| < 5°) {
    // 小误差修正会导致机械臂被压到 15% 速度，运动 1.5s+
    // 但人脸 250ms 后就停止了，机械臂永远追不上
    // 策略：不发，等累积误差大了再说
}
```

### 7.2 运动状态机（5 核心状态）

```cpp
typedef enum {
    STATE_STOP_TO_ACCEL,      // 静止→加速
    STATE_ACCEL,              // 加速
    STATE_ACCEL_TO_CONST,     // 加速→匀速（★ 主窗口）
    STATE_CONST_SPEED,        // 匀速
    STATE_CONST_TO_DECEL,     // 匀速→减速（★ 修正窗口）
    STATE_DECEL_TO_STOP,      // 减速→停止
    STATE_STOP,               // 停止
    STATE_DECEL_STOP_TO_ACCEL // 减速→停止→加速
} MotionState;
```

**已实现**：`MotionContext` 从 `wx_hist`/`wz_hist` 更新，`next_motion_state()` 状态转移完整代码化。

**状态转移规则**：
- 减速中 \|wz\|<3 且下一周期反向增大 → 直接转 **加速**（V 型过零，不停留）
- \|wz\|<3 持续 2 周期 → 才确认 **停止**
- 新状态需连续 2 周期一致才正式切换（过零反转除外）

### 7.3 概率预测器

```cpp
struct Predictor {
    float center;      // 预测中心 (yaw, 度)
    float radius;      // 球体半径 / 椭球短半轴
    float stretch;     // 椭球长半轴增量
    float confidence;  // 置信度 0~1
};

Predictor predict(float yaw, float wz, float ast, MotionState state, float dt)
{
    Predictor p;

    // 基础版：速度不确定性球体
    p.center = yaw + wz * dt;
    p.radius = fabsf(wz) * dt * 0.3f;

    // Plus版：加速度拉伸
    p.stretch = 0.5f * ast * dt * dt;
    float k = 0.0f;

    // Ultra Plus版：状态调制
    switch (state) {
        case STATE_ACCEL:       k = 1.5f; break;
        case STATE_CONST_SPEED: k = 0.3f; break;
        case STATE_JITTER:      k = 0.0f; break;  // 球体，不拉伸
        case STATE_DECEL:       k = -1.0f; break;
        case STATE_STOP:        k = 0.0f; p.radius = 0; break;
    }

    p.center += k * p.stretch;
    p.confidence = 1.0f / (1.0f + p.radius / 10.0f);

    return p;
}
```

### 7.4 主控制逻辑

```cpp
void nrf24_control_update(void)
{
    static uint64_t last_cmd_us = 0;
    static float last_cmd_center = 0.0f;
    static MotionState prev_state = STATE_STOP;

    // 读取共享状态（加锁）
    float wz, yaw;
    float ast[5];
    int ast_cnt;
    // ... 从 g_nrf24_state 复制 ...

    // 状态机
    MotionState state = next_motion_state(prev_state, wz, ast, ast_cnt);
    prev_state = state;

    // 自适应预测窗口
    float dt = 0.4f;  // 默认 400ms
    // 根据预测位移调整 dt...

    // 概率预测
    Predictor pred = predict(yaw, wz, ast[ast_cnt-1], state, dt);

    // 发指令决策
    bool center_moved = fabsf(pred.center - last_cmd_center) > 5.0f;
    bool confident = pred.confidence > 0.5f;
    bool state_ok = (state != STATE_JITTER);
    bool interval_ok = (now_us - last_cmd_us >= 200000);  // 200ms

    if (center_moved && confident && state_ok && interval_ok) {
        // 目标位置生成
        float target_x = ...;  // 基于 pred.center 计算
        float target_y = ...;
        float target_z = 40.0f;

        uart_send_arm_target(target_x, target_y, target_z, 50.0f, 145.0f, 0x00);

        last_cmd_center = pred.center;
        last_cmd_us = now_us;

        printf("[NRF-CMD] state=%s pred=%.2f±%.2f conf=%.2f\n",
               state_name(state), pred.center, pred.radius, pred.confidence);
    } else {
        printf("[NRF-STATE] state=%s wz=%+.2f conf=%.2f (no cmd)\n",
               state_name(state), wz, pred.confidence);
    }
}
```

## 八、关键参数汇总

### 8.1 人脸运动判定

| 参数 | 值 | 说明 |
|:---|:---:|:---|
| 静止阈值 | \|wz\| < 3 deg/s | 速度判定 |
| 静止确认 | 持续 2 周期（100ms） | 避免过零瞬态误判 |
| 加速趋势 | 5 次加速度中 ≥3 次 > 1.0 | 趋势判定窗口 |
| 减速趋势 | 5 次加速度中 ≥3 次 < -1.0 | 趋势判定窗口 |
| 速度抖动 | 加速度正负交替，未突破平台 ±10% | 抖动判定 |

### 8.2 控制触发阈值

| 参数 | 值 | 说明 |
|:---|:---:|:---|
| 最小发指令间隔 | 200ms | 给机械臂至少跑完 phase1~3 |
| 预测中心变化阈值 | 5° | 小于此值不发，避免小位移陷阱 |
| 置信度阈值 | 0.5 | 预测半径过大时不发 |
| 小误差不发 | \|Δyaw\| < 5° | 累积误差，等大了再发 |
| 方向反转紧急间隔 | 100ms | 摇头时允许更频繁更新 |

### 8.3 概率预测参数

| 参数 | 值 | 说明 |
|:---|:---:|:---|
| σ_v（速度不确定系数） | 0.3 | 球体半径缩放 |
| σ_a（加速度不确定系数） | 1.0 | 椭球拉伸缩放 |
| 加速状态拉伸系数 k | 1.5 | 强拉伸 |
| 匀速状态拉伸系数 k | 0.3 | 弱拉伸 |
| 抖动状态拉伸系数 k | 0.0 | 不拉伸，保持球体 |
| 减速状态拉伸系数 k | -1.0 | 反向拉伸 |

### 8.4 预测窗口 Δt

| 预测位移 S_pred | Δt | 原因 |
|:---|:---:|:---|
| < 3cm | 1.5s | 小位移极慢，给机械臂充足时间 |
| 3~15cm | 0.8s | 中等速度 |
| ≥ 15cm | 0.4s | 大位移快，机械臂能迅速到位 |

## 九、下位机配合建议（可选）

当前下位机每次收到指令都重置 S 曲线：`Speed_Plan_State = init`。

若允许修改下位机，建议增加**指令变化幅度判断**：

```c
// 当前下位机行为：无条件重置
Speed_Plan_State = init;

// 建议改为：小变化不重置，大变化或反向才重置
float delta = fabsf(new_target - old_target);
bool same_dir = (new_target - actual) * (old_target - actual) > 0;

if (delta > 0.05f || !same_dir) {  // 5cm 阈值或反向
    Speed_Plan_State = init;
} else {
    // 小变化：只更新 error_s，保持当前 phase 平滑过渡
    error_s = new_target - position_actual;
}
```

这样上位机可以实现真正的高频更新（30ms），下位机像追踪移动靶一样平滑跟随。

## 十、舵机控制（新增）

### 10.1 问题：J4 与机械臂耦合

下位机逆运动学：
```c
Coordinate_Inverse_Settlement(X, Y, Z, Servo_Angle, &J1, &J2, &J3);
```

**Servo1 是输入**，改变它会重新解算 J1/J2/J3。

| Servo1 变化 | L2_virtual 变化 | J2/J3 变化 | 末端偏移 |
|:-----------:|:---------------:|:----------:|:--------:|
| ±20° | ±25mm | ±8° | ~±2cm |
| ±40° | ±50mm | ±16° | ~±5cm |

### 10.2 控制策略

**约束**：不改下位机、不改结构、只调 1~2 次、低频反馈。

| 方案 | 做法 | 需要数据 |
|------|------|---------|
| **A. 简单标定** | 当前源码近似为 `servo1 = 55° + K × delta_pitch`，抬头/低头分段增益 | 不需要常数，不需要反馈 |
| **B. 正运动学校正** | 反馈 J1/J2/J3 → 正运动学 → 偏差计算 | 6 个几何常数 + J1/J2/J3 反馈 |

**推荐**：先 A 后 B。标定手册见 `docs/servo-calibration-guide.md`。

### 10.3 上位机状态机（舵机）

```cpp
typedef enum {
    SERVO_STATE_ARM_MOVING,     // 机械臂运动中，J4 固定
    SERVO_STATE_ARM_STABLE,     // 机械臂到位，等待触发
    SERVO_STATE_SEND_ADJUST,    // 发 J4 补偿令（只发一次）
    SERVO_STATE_WAIT_DONE,      // 等待执行
    SERVO_STATE_IDLE            // 完成
} ServoControlState;
```

**触发条件**：
1. `g_uart_move_complete`（机械臂到位）
2. `|delta_roll| > 5°`
3. 距离上次调整 > 2s
