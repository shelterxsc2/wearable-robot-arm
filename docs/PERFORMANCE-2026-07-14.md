# 完整视觉性能阶段测试（2026-07-14）

## 测试边界

- 测试发生于迁移工作树，结果与代码随后提交到 `no-arm-test`；`build/cc` 为当日重新编译版本。
- 完整 RTSP 管线：1920×1080@30 输入、Body、Face/PnP、双手异步旁路、OSD、H264/RTSP。
- `VOICE_KWS_DISABLE=1`，本轮只完成无 KWS 基线；用户要求停止后未运行 KWS A/B 组。
- 机械臂保持默认收起，NRF/UART 目标发送被门控。
- 指标每 5 秒采样；剔除前 60 秒预热后使用 87 个窗口，稳定段约 7.3 分钟；资源采样总长 497 秒。
- 场景中有人体和双手活动，手势旁路持续工作。结果只代表本次现场画面。

## 阶段结论

- 基线平均满足“大于 13 FPS”，但最低 5 秒窗口只有 10 FPS，尚不满足“任意连续 10 秒 >13 FPS”的严格目标。
- Body 仍是主要耗时；Hand 尾延迟约为中位数的 2.2 倍，需要在 KWS A/B 时继续观察 NPU 调度竞争。
- RSS 在本轮无持续增长，温度升至约 70°C，需更长时间测试确认热稳态及降频行为。
- 因未运行 KWS 组，不能给出语音开启后的 FPS 降幅、Body P95 增幅或整机 KWS CPU/RSS 墳量。

设备上的原始数据位于 `/tmp/fourth_perf_baseline.log`、`/tmp/fourth_perf_baseline_metrics.csv`，不随 Git 提交。

## Hand interval=3 + KWS（5 分钟追加测试）

- Hand 每 3 个视觉帧采样，仍连续 3 次确认。
- KWS 使用 USB 麦克风 `plughw:3,0`、CPU Sherpa-ONNX 和 Silero VAD 软门控。
- 比较稳定段取 42 个 5 秒窗口，剔除启动和早期模式干扰。

| 指标 | interval=2、无 KWS | interval=3、KWS |
|---|---:|---:|
| 平均 FPS | 16.01 | 16.25 |
| FPS P05 / P50 / P95 | 12 / 18 / 18 | 12 / 18 / 18 |
| Body 平均 | 50.37 ms | 50.05 ms |
| 完整 AI 平均 | 59.07 ms | 58.53 ms |
| Hand 平均 / P95 | 15.90 / 30.80 ms | 13.31 / 28.60 ms |
| 主进程 CPU | 143.76% | 142.95% |
| KWS CPU / RSS | 0 | 23.23% 单核 / 80.63 MiB |
| 最高温度 | 70.23°C | 70.23°C |

阶段上 interval=3 抵消了 KWS 对视觉吞吐的影响，FPS 分位数没有退化；两组时长、动作和模式切换不完全相同，因此不能把约 1.5% 的平均提升视为精确收益。

严重安全发现：现场音频在 5 分钟内产生 32 次 KWS 事件，包含 `开机` 和 `关机`。本轮 `开机` 因 H7 未报告 `init success` 被安全状态机拒绝，机械臂没有展开，但当前阈值 0.25 不适合直接开放机械控制。完成真实语料/噪声标定、提高阈值并为开关机增加独立确认前，应禁用语音开关机动作。

设备上的原始数据位于 `/tmp/fourth_perf_hand3_kws.log`、`/tmp/fourth_perf_hand3_kws_metrics.csv`，不随 Git 提交。
